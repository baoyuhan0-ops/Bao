# NoshFriends Android 工程说明 (中国 🇨🇳 · 新加坡 🇸🇬 · 英国 🇬🇧 密友专享版)

## 核心功能
1. **拍照食物识别热量**：支持调用 Android 原生相机或相册拍下每顿饭，自动拆解食材克重、总热量 (kcal) 与三大营养素 (蛋白质/碳水/脂肪)，支持 0.5x~1.5x 份量一键重算，并可选配置 Gemini Vision API Key。
2. **每日摄入总热量统计**：顶部 Nosh 风格圆环进度条实时统计当日已摄入热量、剩余热量额度、三餐分布及过去 7 天趋势对比。
3. **中新英跨国好友实时共享**：内置中新 (UTC+8) 与英国伦敦 (UTC+0) 双时区状态栏、好友今日总摄入排行榜 (`#NOSH-886` 房间) 及三地餐桌实拍流，无需依赖 Google Play 服务即可在中国大陆、新加坡和英国无障碍使用。
4. **Nosh 极简高可视化卡片**：每顿饭保留实拍照片，照片上直接挂载食材热量锚点与毛玻璃热量印章，可一键生成「Nosh 美食热量海报卡」。

## 如何打包生成 Android APK 安装包
1. 使用 **Android Studio** 打开本工程目录。
2. 点击顶部菜单 **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**。
3. 将生成的 `app-debug.apk` 直接发到微信群或 WhatsApp 群，中国、新加坡和英国的好友点击即可安装。
