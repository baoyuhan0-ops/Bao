📱 安卓手机安装与跨国使用说明

方式一：直接编译原生 Android APK（已附完整源码包）

下载附带的 nosh_friends_android_project.zip，用 Android Studio 打开即可一键运行 Build APK(s) 生成安装包，直接发到微信群或 WhatsApp 群给中国、新加坡、英国的朋友安装。

由于中国大陆好友通常没有 Google Play，将单文件版托管至任意静态链接后，三地好友用安卓 Chrome / Edge / 系统浏览器打开，点击菜单「添加到主屏幕」，即可获得全屏原生 App 图标与相机拍照体验。
